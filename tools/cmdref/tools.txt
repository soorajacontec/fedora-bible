@git ~~ Version control
$ git [OPTIONS] COMMAND [ARGS]
- init / clone URL ~~ New repo / copy one
- status ~~ What changed (-s short)
- add FILE / add -p ~~ Stage files / stage hunks interactively
- commit -m "msg" ~~ Record staged changes (--amend fixes the last)
- log --oneline --graph ~~ History
- diff / diff --staged ~~ Unstaged / staged changes
- branch / switch -c NAME ~~ List / create + switch branches
- merge / rebase ~~ Combine branches
- pull / push ~~ Sync with the remote
- fetch ~~ Download without merging
- stash / stash pop ~~ Park changes temporarily
- restore FILE ~~ Discard changes to a file
- reset --soft HEAD~1 ~~ Undo last commit, keep changes
- revert COMMIT ~~ New commit that undoes another
- tag v1.0 ~~ Label a release
- remote -v ~~ Remotes
- blame FILE ~~ Who changed each line
- bisect ~~ Find the commit that broke something
> git status -s ~~ Short status
> git add -p && git commit -m "Fix login bug" ~~ Commit selected changes
> git log --oneline --graph --all | head -20 ~~ History graph
> git switch -c feature/x ~~ New branch
> git stash && git pull --rebase && git stash pop ~~ Update while you have local changes

@iostat ~~ Disk and CPU I/O statistics (sysstat)
$ iostat [OPTIONS] [INTERVAL [COUNT]]
- -x ~~ Extended stats (%util, await)
- -h ~~ Human-readable
- -z ~~ Hide idle devices
> iostat -xz 2 ~~ Live disk load every 2 s

@vmstat ~~ Memory, CPU, swap activity
$ vmstat [INTERVAL [COUNT]]
- -s ~~ Memory totals
- -w ~~ Wide output
> vmstat 1 5 ~~ 5 samples, 1 s apart (watch si/so for swapping)

@watch ~~ Repeat a command and show its output
$ watch [OPTIONS] COMMAND
- -n SEC ~~ Interval
- -d ~~ Highlight changes
- -t ~~ No header
> watch -n 2 -d 'ss -s' ~~ Live socket summary
