@pandoc ~~ Universal document converter
$ pandoc [OPTIONS] INPUT -o OUTPUT
- -f / -t FORMAT ~~ Input / output format
- -o FILE ~~ Output (format from extension)
- -s ~~ Standalone document
- --toc ~~ Table of contents
- --pdf-engine=NAME ~~ typst, weasyprint, xelatex…
- --extract-media=DIR ~~ Save embedded images
- --metadata KEY=VAL ~~ Title, author…
- --reference-doc=FILE ~~ Styles for docx/odt
> pandoc notes.md -o notes.docx ~~ Markdown to Word

@aria2c ~~ Multi-connection download utility (HTTP, FTP, BitTorrent)
$ aria2c [OPTIONS] URI...
- -x N ~~ Connections per server
- -s N ~~ Split into N pieces
- -c ~~ Continue a download
- -i FILE ~~ URLs from a file
- -j N ~~ Parallel downloads
- -d DIR / -o NAME ~~ Folder / file name
- --max-download-limit=RATE ~~ Speed limit
- --seed-time=MIN ~~ Torrent seeding time
> aria2c -x 8 -s 8 https://example.com/big.iso ~~ Faster download
