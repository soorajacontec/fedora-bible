@dnf ~~ Fedora package manager (DNF5)
$ dnf [OPTIONS] COMMAND [ARGS]...
- install PKG ~~ Install packages (also local .rpm files, @groups)
- remove PKG ~~ Remove packages
- upgrade ~~ Upgrade everything (or named packages)
- search WORD ~~ Search names and summaries
- info PKG ~~ Details: version, size, repo, description
- list --installed ~~ Installed packages
- provides FILE ~~ Which package provides a file/command
- repoquery ~~ Query repository metadata (--userinstalled, --requires…)
- history ~~ Past transactions (list, info, undo)
- group list / install ~~ Package groups
- autoremove ~~ Remove unneeded dependencies
- clean all ~~ Clear cached metadata and packages
- makecache ~~ Refresh metadata now
- swap A B ~~ Replace one package with another
- downgrade PKG ~~ Go back a version
- copr enable USER/PROJECT ~~ Add a COPR repository
- -y ~~ Assume yes
- --refresh ~~ Force fresh metadata
- --allowerasing ~~ Allow removing conflicting packages
- --best ~~ Insist on the newest versions
- --setopt=install_weak_deps=False ~~ Skip weak (recommended) deps
> sudo dnf upgrade --refresh ~~ Update the whole system
> sudo dnf install htop ~~ Install a package
> dnf provides /usr/bin/dig ~~ Which package has a command
> dnf history list | head ~~ Recent transactions
> sudo dnf history undo last ~~ Undo the last transaction
> sudo dnf autoremove ~~ Remove orphaned dependencies

@rpm ~~ Low-level RPM package tool
$ rpm -q[OPTIONS] PACKAGE
$ rpm -V PACKAGE
- -qa ~~ All installed packages
- -qi PKG ~~ Package info
- -ql PKG ~~ Files in a package
- -qf FILE ~~ Which package owns a file
- -qR PKG ~~ What it requires
- -q --changelog PKG ~~ Change log
- -qc PKG ~~ Config files only
- -V PKG ~~ Verify files against the package
- -Va ~~ Verify every package
- --last ~~ Sort -qa by install date
- -K FILE.rpm ~~ Check a downloaded RPM's signature
> rpm -qf /usr/bin/ssh ~~ Owner of a file
> rpm -qa --last | head ~~ Most recently installed
> rpm -ql nginx | grep conf ~~ Config files of a package
> rpm -V openssh-server ~~ Was anything modified?

- run APP ~~ Start an app

- info APP ~~ Details (-M permissions)
- override APP ~~ Change permissions (--filesystem, --socket…)

- ps / kill ~~ Running apps
- history ~~ Install/update log
- mask / pin ~~ Freeze an app / keep a runtime
- repair ~~ Fix a broken install
- --user / --system ~~ Per-user or system-wide installation
> flatpak install flathub org.gimp.GIMP ~~ Install from Flathub
> flatpak update -y ~~ Update all
> flatpak list --app --columns=application,version,size ~~ Apps with sizes
> flatpak uninstall --unused ~~ Clean up runtimes

@systemctl ~~ Control systemd services and the system
$ systemctl [OPTIONS] COMMAND [UNIT]...
- status UNIT ~~ State, recent log lines, PID
- start / stop / restart UNIT ~~ Now
- reload UNIT ~~ Re-read config without restart
- enable / disable UNIT ~~ At boot (--now: also start/stop)
- is-active / is-enabled ~~ Scripting checks
- mask / unmask UNIT ~~ Block a unit completely
- list-units ~~ Loaded units (--type=service, --state=failed)
- list-unit-files ~~ Installed units + enabled state
- list-timers ~~ Scheduled timers
- --failed ~~ Failed units
- cat UNIT ~~ Show the unit file(s)
- edit UNIT ~~ Create a drop-in override
- daemon-reload ~~ After editing unit files
- reboot / poweroff / suspend ~~ Power
- --user ~~ Your per-user services
> systemctl status sshd ~~ Is it running?
> sudo systemctl enable --now nginx ~~ Start + at every boot
> systemctl --failed ~~ What failed
> sudo systemctl edit nginx ~~ Override settings safely
> systemctl list-timers ~~ When timers run next

@journalctl ~~ Read the systemd journal (logs)
$ journalctl [OPTIONS] [MATCHES]
- -u UNIT ~~ One service
- -f ~~ Follow new entries
- -b ~~ This boot (-b -1 = previous)
- -p err ~~ Priority: emerg…err…info…debug
- -k ~~ Kernel messages
- --since / --until ~~ "1 hour ago", "today", "2026-09-30 10:00"
- -n N ~~ Last N lines
- -e ~~ Jump to the end
- -o cat|json|short-iso ~~ Output format
- -g PATTERN ~~ grep messages
- --list-boots ~~ Boot history
- --disk-usage ~~ Journal size
- --vacuum-size=500M ~~ Shrink the journal
- --user ~~ Your user journal
> journalctl -u sshd -f ~~ Follow one service
> journalctl -b -p err ~~ Errors this boot
> journalctl --since "1 hour ago" ~~ Recent entries
> journalctl -b -1 -e ~~ End of the previous boot (crash?)
> sudo journalctl --vacuum-size=500M ~~ Free space

@ps ~~ Snapshot of running processes
$ ps [OPTIONS]
- aux ~~ Every process, BSD style
- -ef ~~ Every process, full format
- -u USER ~~ One user's processes
- -p PID ~~ Specific processes
- -o COLS ~~ Custom columns (pid,ppid,%cpu,%mem,cmd)
- --sort=-%mem ~~ Sort by column (- = descending)
- -L ~~ Show threads
- -Z ~~ SELinux contexts
- f / --forest ~~ Process tree
> ps aux --sort=-%mem | head ~~ Top memory users
> ps -eo pid,ppid,%cpu,%mem,cmd --sort=-%cpu | head ~~ Top CPU users
> ps -ef | grep [n]ginx ~~ Find a process (bracket trick hides grep)
> ps -p 1234 -o etime= ~~ How long a process has run

@top ~~ Live process viewer
$ top [OPTIONS]
- -o FIELD ~~ Sort by %CPU, %MEM…
- -u USER ~~ Only one user
- -p PID ~~ Only these PIDs
- -b -n 1 ~~ One batch snapshot (scripts)
- P / M / T ~~ (inside) sort by CPU / memory / time
- k ~~ (inside) kill a process
- 1 ~~ (inside) per-CPU view
- q ~~ (inside) quit
> top -o %MEM ~~ Sorted by memory
> top -b -n 1 | head -15 ~~ Snapshot for a report
